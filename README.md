## ✨ Overview
This repository serves as a clean and unopinionated baseline for Quality Island's Page Object Model (POM) implementation. It offers a solid starting point for building scalable and maintainable QA automation suites, emphasizing clarity and best practices.

## 🧱 Tech Stack
*   **Java:** The primary programming language for development.
*   **Selenium WebDriver:** For browser automation and interaction.
*   **Maven:** Project object model for builds, dependency, and project management.

## 🚀 Features
*   Strict adherence to the Page Object Model pattern.
*   Clear separation of concerns between tests, pages, and utilities.
*   Modular and extensible architecture.
*   Ready-to-use project structure for immediate development.

## 🛠️ Quickstart
To get started, clone the repository and execute the tests using Maven.

```bash
git clone https://github.com/rothfick/POM.git
cd POM
mvn test
```

## 🗺️ Project Structure
The project is organized with `src/main/java` containing core application logic (if any), and `src/test/java` holding the test suites, page objects, and utility classes. Configuration files like `pom.xml` manage dependencies and project build settings, while `.idea` stores IntelliJ IDE-specific configurations, and `.gitignore` specifies files to be ignored by Git.
